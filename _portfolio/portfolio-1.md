excerpt: "A bilingual (R + Python) data management and statistical analysis pipeline for synthetic cohort data, designed to demonstrate rigorous data cleaning, validation, and reproducible research practices for epidemiological studies.<br/> This project simulates a realistic maternal-child health cohort (N=1,500) with variables mirroring the exposome framework—maternal age, BMI, glucose, environmental exposure, smoking status, and a binary hypertension outcome. It implements a complete Data Manager workflow: synthetic data generation with MCAR missing values, systematic cleaning (median imputation, outlier capping, derived variable creation), automated quality control, descriptive statistics, and statistical modeling (logistic regression with ROC/AUC evaluation).<br/>Built with R (<i>tidyverse, ggplot2, broom, pROC</i>) as the primary statistical language and Python (<i>pandas, numpy, statsmodels, matplotlib, seaborn</i>) as a complementary implementation, demonstrating full interoperability between ecosystems. The project emphasizes reproducibility through scripted pipelines, version‑controlled code, and comprehensive documentation including a data dictionary and quality reports.<br/> GitHub repo: [cohort_demo_project](https://github.com/tantikristanti/cohort_demo_project)<br/><img src='/images/portfolio/cohort-demo-project.png'><br/>"
